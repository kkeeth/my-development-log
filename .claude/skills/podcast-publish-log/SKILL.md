# 配信管理スプレッドシートの更新

## 前提（初回セットアップ）

この skill は以下が揃っていないと動かない．未設定なら**先にユーザーに確認する**．

### 対象シート

- URL：https://docs.google.com/spreadsheets/d/1XuV55f2pDiTu8UihiD9_1cZlvFMbRGsPrZpQhcx72fI/edit#gid=708109032

**このウェブアプリはデスクトップアプリの定期タスクと共用**である．
`update_episode` / `update_stock` の 2 アクションはそちらが依存しているので，
`Code.gs` から**消したり引数を変えたりしてはいけない**．

### 1. Apps Script の更新

既にデプロイ済みのスクリプトがある．`scripts/gas/Code.gs` はそれを**拡張したもの**で，
既存 2 アクションは一字も変えていない．

1. スプレッドシートを開く → **拡張機能 → Apps Script**
2. `scripts/gas/Code.gs` の内容で既存コードを置き換えて保存
3. **プロジェクトの設定 → スクリプト プロパティ** に `API_TOKEN` を追加．
   値は `openssl rand -hex 32` で生成した文字列
4. **デプロイ → デプロイを管理 → 既存デプロイの編集（鉛筆）→ バージョン「新バージョン」→ デプロイ**
   - ⚠️ 「新しいデプロイ」を選ぶと **URL が変わり，デスクトップアプリの定期タスクが止まる**

### 2. 環境変数

```fish
set -Ux PODCAST_SHEET_WEBAPP_URL <既存デプロイと同じ .../exec の URL>
set -Ux PODCAST_SHEET_TOKEN      <API_TOKEN と同じ値>
set -Ux PODCAST_SHEET_TAB        エピソード管理
```

タブは **gid ではなく名前**で指定する．タブ一覧は末尾の「シート構成」に記録済み．
構成が変わったときは次で取り直す．

```bash
python3 .claude/skills/podcast-publish-log/scripts/sheets.py tabs
```

`--url` / `--token` / `--tab` は**サブコマンドの後ろ**に書ける
（例：`sheets.py rows --tab 企画ストック（雨宿り） --max 10`）．

### 認証の考え方

デプロイの「アクセスできるユーザー：全員」は，URL を知る誰もが POST できる状態を意味する．

- **既存 2 アクション**（`update_episode` / `update_stock`）は**トークン不要**のまま．
  デスクトップアプリを壊さないため．できることはタイトル一致行の限られた列の更新だけで，
  影響範囲が狭い
- **追加アクション**は**トークン必須**．シート全体を読み書きできるため

デスクトップアプリ側もトークンを送るようにしたら，`Code.gs` の
`REQUIRE_TOKEN_FOR_ALL` を `true` にして全体を保護する．

**URL とトークンはどちらも秘密**として扱う．リポジトリや Slack に貼らない．

### なぜ Sheets API ではなく Apps Script なのか（調査済み・2026-08-08）

- gcloud の ADC は gcloud 内蔵の共有 OAuth クライアント（`client_id 764086051850-...`）を使う．
  このクライアントは `spreadsheets` のような**機微スコープを要求できない**．
  `--scopes` を付けて login すると Google 側で「**このアプリはブロックされます**」と弾かれる
- gcloud 自体も Claude Code のサンドボックス内では `~/.config/gcloud/credentials.db` へ
  書き込めず動作しない（`gcloud auth list` すらエラーになる）
- サービスアカウント方式なら通るが GCP プロジェクトが必要になる

Apps Script はスプレッドシート所有者の権限で動くため，GCP も OAuth も不要になる．

### 3. サンドボックスのネットワーク許可

Claude Code のサンドボックスは既定で外部通信を遮断する．
**2026-08-08 に設定済み**（`.claude/settings.local.json` の
`sandbox.network.allowedDomains` に `script.google.com` と
`script.googleusercontent.com`）．キー名は `allowedHosts` ではなく `allowedDomains`．

`.../exec` は `script.googleusercontent.com` にリダイレクトして応答を返すため，
**両方のドメインが必要**である．変更するときは `/config` か `update-config` skill を使う．

なお `uv` はこのサンドボックス内で panic するため使わない．
スクリプトは**標準ライブラリのみ**で書かれており `python3` で直接動く．

## 手順

### 1. シートの構造を把握する

**毎回まずヘッダを読む**．列構成を推測しない．

```bash
python3 .claude/skills/podcast-publish-log/scripts/sheets.py header
```

初回は列の意味をユーザーに確認し，このファイル末尾の「列マッピング」に書き残す．

### 2. 台本から値を集める

対象の台本 md を読み，以下を拾う．足りないものはユーザーに聞く．

| 項目 | 取得元 |
| --- | --- |
| タイトル | 台本冒頭の `# ` 行，または `## 📣 配信メタ` の採用タイトル |
| 概要欄 | `## 📣 配信メタ` の概要欄 |
| 台本ファイル | 相対パス |
| 配信ステータス | 冒頭の `> **配信ステータス**：` |
| 配信 URL | 冒頭の `> **配信URL**：` |
| タグ | `## 🎙️ 収録メモ` のタグ |
| 尺 | `## 🎙️ 収録メモ` の尺 |
| 収録日・配信日 | ユーザーに確認（推測しない） |

### 3. 既存行を確認する

同じ回が既に登録されていないか，タイトル列で検索する．
**列は位置ではなくヘッダ名で指定する**（列が増減しても壊れないため）．

```bash
python3 .claude/skills/podcast-publish-log/scripts/sheets.py find --key-col タイトル --key "<タイトル>"
```

- ヒット無し → `append`
- ヒットあり → `update`．**上書き前に現在の行を `rows` で見せ，ユーザーに確認を取る**
- 複数ヒット → Apps Script 側が中断する．どの行かを人間に決めてもらう

### 4. 書き込む

書き込む内容を**実行前に必ず表形式で提示し，承認を得る**．
スプレッドシートはデスクトップアプリの定期タスクも書き込む共有資産であり，取り消しが効きにくい．

新規エピソードの追加：

```bash
python3 .claude/skills/podcast-publish-log/scripts/sheets.py append \
  --fields '{"タイトル":"...","カテゴリ":"...","配信予定日":"2026-08-15","ステータス":"未配信"}'
```

既存エピソードの更新（指定したフィールドだけを書き換える）：

```bash
python3 .claude/skills/podcast-publish-log/scripts/sheets.py update \
  --key-col タイトル --key "<タイトル>" \
  --fields '{"ステータス":"配信済み","配信日":"2026-08-15"}'
```

ステータスと配信日だけの更新なら，デスクトップアプリと同じ経路も使える
（トークン不要，列名固定）：

```bash
python3 .claude/skills/podcast-publish-log/scripts/sheets.py update-episode \
  --title "<タイトル>" --status 配信済み --date 2026-08-15
```

企画ストックのネタを消化したら，使用済みに倒す：

```bash
python3 .claude/skills/podcast-publish-log/scripts/sheets.py update-stock \
  --title "<タイトル案>" --usage 使用
```

### 5. 台本側も同期する

配信済みにした場合は，台本冒頭のブロックも合わせて更新する．

```markdown
> **配信ステータス**：配信済み
> **配信URL**：https://art19.com/shows/kkeethengineers/episodes/<uuid>
```

## 注意

- **書き込み前に必ず確認を取る**．とくに `update` は既存データを消す．
  `update` は上書き前の行内容を `before` として返すので，誤爆したらそれで戻せる
- 日付は推測しない．「今日」で良いかを聞く
- エラーが出たときの切り分け：
  - `Apps Script エラー: 認証に失敗しました` → `PODCAST_SHEET_TOKEN` とスクリプトプロパティの不一致
  - `Apps Script エラー: 不明な action` → `Code.gs` が古い．**再デプロイ**が必要
  - `JSON でない応答` → デプロイの「アクセスできるユーザー」が『全員』になっていない
  - `接続に失敗しました` → サンドボックスのネットワーク許可
- `Code.gs` を直したら再デプロイするまで反映されない．挙動が変わらないときは真っ先に疑う

## シート構成

### タブ一覧（2026-08-09 実測）

| タブ名 | gid | 行数 | この skill での役割 |
| --- | --- | --- | --- |
| ダッシュボード | 708109032 | 9 | 触らない（集計用と思われる） |
| **エピソード管理** | 0 | 31 | 配信回の登録・更新先 |
| 月次レポート | 661822135 | 18 | 触らない |
| **企画ストック（雨宿り）** | 1863500694 | 52 | WEB小噺 のネタ帳．`podcast-research` の保存先 |
| 企画ストック（オナマエラジオ） | 1015141422 | 52 | 別番組．**この skill では触らない** |
| 特集・拡張企画 | 1275639494 | 27 | 触らない |
| フォームの回答 | 1565046690 | 17 | 触らない（お便りフォーム） |

⚠️ スプレッドシート URL の `gid=708109032` は**ダッシュボード**であってエピソード管理ではない．
`PODCAST_SHEET_TAB` の既定値は `エピソード管理` にすること．

### エピソード管理（`Code.gs` から判明．末尾は未確認）

```
No / タイトル / カテゴリ / 配信予定日 / 配信日 / ステータス / ...
```

- 台本の `# ` 行または `## 📣 配信メタ` の採用タイトルが `タイトル` に対応する
- `ステータス` の語彙は未確認．書き込む前に `rows` で既存値を見て合わせること
  （台本側の表記は「未配信」「配信済み」）

### 企画ストック（雨宿り）

```
No. / カテゴリ / タイトル案 / メモ / 使用/ボツ / 使用エピソード番号
```

- `podcast-research` skill が出したネタ候補の保存先はここが本命．
  ローカルの `src/DRAFTS/PODCASTS/ideas.md` は補助
- ネタを台本化したら `使用/ボツ` を「使用」に倒す

### ⚠️ 既存 `update_stock` の制約

既存コードの `findSheetByHeader_` は **条件に合う最初のタブを返す**．
`タイトル案` と `使用/ボツ` を持つタブは 2 つある（雨宿り／オナマエラジオ）ため，
`update_stock` は**常に「企画ストック（雨宿り）」しか対象にしない**．

この skill は WEB小噺 専用なので実害はない．
ただしオナマエラジオ側を更新したくなったら，`update_stock` に `tab` 引数を足す必要がある
（デスクトップアプリとの後方互換のため，省略時は現在の挙動を維持すること）．
