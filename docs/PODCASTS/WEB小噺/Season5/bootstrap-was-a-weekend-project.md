### 本題

- 【つかみ】2010年代，やたら似たデザインのWebサイトが増えた時期があった．青いボタンに角丸カード，あのテイストの正体はほぼ全部「Bootstrap」だった
- 【背景/歴史】始まりは2010年，Twitter社内．エンジニアそれぞれが自分の好きなツールやスタイルでバラバラに開発していて，社内の一貫性が崩壊していた．それを見かねたエンジニアのMark OttoとJacob Thorntonが，社内共通のUIキットを作り始めた．最初の名前は「Twitter Blueprint」，あくまで社内ツールだった
- 【メインの小噺・裏話】開発から数ヶ月後，Twitter社内で初の「Hack Week」が開催され，そこでこのプロジェクトが爆発的に広まった．スキルレベルを問わず社内のいろんな人が触り始めて，1年以上，社内の公式スタイルガイドとして使われ続けた．そして2011年8月19日（金曜日）に，社外向けにオープンソース化．このタイミングで名前も「Bootstrap」に変わった
- 【意外な事実や補足】「Bootstrap」という名前，実は二重の意味がかかっている．ひとつは「靴のつまみ革（bootstrap）を引っ張って自力で立ち上がる」という英語の慣用句．もうひとつはコンピュータを「起動する」という意味の“boot”．つまり「ゼロから，自分の力でパッと何かを立ち上げる」というニュアンスを名前に込めている．ちなみに初期バージョンに入っていたアイコンセット「Glyphicons」は本来有料だが，作者の厚意でBootstrapには無償提供されていたというこぼれ話もある．公開後は爆発的に広まり，GitHubで最も星（スター）を集めたプロジェクトの一つになった
- 【まとめ・締めのひとこと】社内の「みんなバラバラで困る」を解決するために週末感覚で作られたツールが，気づけば世界中のWebサイトの見た目を決める存在になっていた，という話でした
