台本

オープニング

【ジングル】 はい，どうもこんにちは．「雨宿りとWEBの小噺」始まりました．気づきの配達屋 Keethこと桑原です．

この番組では，気にも留めていなかったものに光を当てることで，世界の見え方が少し変わるかもしれない，そんな Web 業界の裏話や小噺をご紹介しております．

今回のお題は「ボツになった番組名，全部話します」です．

本題

きっかけは，金子さんとのコラボ収録

今回はいつもと趣向を変えて，この番組そのものの裏話です．

先日，「プロジェクトをベターにする話をしよう」という番組をされている金子さんと，コラボ収録をさせていただきました．収録した回は，今まさに金子さんに編集していただいているところです．

金子さんとは，Web Creator Podcast Day 2026 で知り合いました．しかも出番の順番が，僕のちょうど 1 つ前だったんですよ．交代のときに顔を合わせて軽く会釈して，そのあとの懇親会でお話しさせていただきました．

実は開催前にも，1 つ前の番組さんということで，金子さんの番組のお便りフォームから「当日はよろしくお願いします」と軽くごあいさつを送っていたんです．その接点もあって，イベントのあとに僕のほうから「コラボ配信しませんか」とお誘いしたら，快く引き受けてくださいました．

で，そのコラボ収録で，金子さんからこんな質問をいただいたんです．「雨宿りとWEBの小噺の『雨宿り』って，なんでこういう名前にしたんですか」と．

「雨宿り」に込めたもの

そのとき僕がお話ししたのは，こんな背景です．

今って，降ってくる情報の量がとにかく多いじゃないですか．僕はこれを，よく雨にたとえています．

ただ，雨そのものが悪いものだとは思っていないんです．雨がまったく降らない世界というのは，人間の暮らしとしてはナンセンスで，雨は作物を育てるし，そのまま川になって流れていく．地球の循環の中で，雨はものすごく大きな役割を担っています．

それに，僕は 6 月生まれでして．梅雨の時期に生まれたからか，雨がやっぱり好きなんですよね．たまに，スマホも持たずに，傘だけさして，雨音を聞きながら歩く，なんてこともします．

ただ，今の情報の雨は，さすがに多すぎる．だから，ちょっとだけ雨宿りをしてほしいんです．傘をさして雨を防ぐ，でもいいんですけど，軒先で少しだけ雨をよけて，その間に，ちゃんと休む．車でいうとアイドリングのような時間に，雑談とか小噺を聞いてもらって，ギアをいったん止めてほしい．そういうひとときを届けたくて，「雨宿り」と付けました．

話しながら，まとまっているようで，まとまっていないなと自分でも思ったんですけど（笑），なんとなく金子さんには伝わったらしくて．

「WEBの小噺」に込めたもの

後ろ半分の「WEBの小噺」は，もっと単純です．僕が Web 業界の話が好きだから．

Web テクノロジーって，難しそうだし，自分には遠いものだと思っている方も多いと思います．でも実は，すごく身近だったり，こんな面白い話が裏にあったりする．そういうことを知ると，テクノロジーがもうちょっとだけ身近になったり，面白いものだなくらいに思ってもらえるんじゃないか．そんな思いを込めています．

技術の専門的な解説とか，これで何ができるとか，どういう効果があるとか，そういうちゃんとした話は，強いエンジニアの方がたくさん発信されています．なのでそこは全部お任せして，僕はそうじゃない側面とか，裏話のほうをやりたい．そうお話ししました．

これが金子さんにはかなり響いたらしくて，僕も僕ですごく嬉しかったんですよ．番組名は本当にこだわったので．金子さんも，ご自身の番組名にはすごく悩まれたそうです．

で，僕が「こだわったけど，他にも名前の候補はいっぱいあったんですよ」とこぼしたら，金子さんが「そのボツ案も聞いてみたい」「他にどんな名前を考えたのか知りたい」と言ってくださって．

僕も，それは 1 本の回になるなと思いました．というわけで今回は，この番組の名前が，どんな変遷と，どんなボツ案を経て「雨宿りとWEBの小噺」になったのか，余すところなくお話しします．候補は本当にたくさんあるので，今回はちょっと長くなります．

番組名の変遷

まず，今の正式な番組名は「雨宿りとWEBの小噺.fm」です．ただ「.fm」は，あってもなくても，くらいの扱いですね．

最初の番組名は，「Web業界の何でも雑談室」でした．しかもこの番組ではなくて，別のプラットフォーム，stand.fm で始めたときに最初に名乗った名前です．

そこから，もう少しテクノロジーに寄せた話をしたくなって，「キースの陽気な雑談チャンネル」という名前に変えたはずです．この名前で，ずいぶん長くやりました．

転機になったのが，ノックスメディアの金さんという方が運営されている，「ポッドキャストの学校」というオンラインスクールです．そこで研修を受けさせていただいて，改めてちゃんとブランドを考えたくなったんですね．この番組を聴いた人にどうなってほしいか，どんな印象を持ってほしいか，そもそもこの番組は何を発信するものなのか．それを明確に決めて，作り直したくなりました．

そこで，リブランディングとして，名前と，番組の構成と，コンセプトと，アートワークをまとめて変えることにしたんです．

まずは，他の番組の名前を集めた

名前を考えるにあたって，最初にやったのは，テック系の番組名を集めることでした．どんな番組があって，名前に共通項がないか，というところから入ったんです．

当時はまだ，今ほどみんなが AI について語っていない時代でした．番組名に「AI」と付いた番組も，ほとんどなかったんですよ．今ならランキングの上位にも AI 系の番組がいくつも入っていますけど，それは除いて，当時僕が探したり，よく聴いていたり，ランキング上位だったりした番組の名前をざっと書き集めました．

読み上げますね．

ゆるコンピュータ科学ラジオ． Rebuild.fm． backspace.fm． fukabori.fm． Off Topic． マジカル FM． ものづくりのラジオ． セキュリティのアレ． EM.FM． 暇人プログラマーの週末エンジニアリングレッスン． Qiita FM． マミット FM． mozaic.fm． しがないラジオ．

他にもたくさんありました．で，ここに書いていないんですけど，僕の中で「これはもう完成している」「この名前を丸パクリしたい」と思った番組名があります．リブランディングの回でもさんざん言ったので，もう何番煎じか分からないんですけど，もう一度言わせてください．

「論より動くもの.fm」です．

STORES の CTO の藤村さんがやっている番組なんですけど，この番組名は，まさにという感じでした．本気で，いい名前を付けたなと今でも思っています．

「ラジオ」か「FM」か，何も付けないか

集めた名前を眺めて，最初に気になったのが，後ろに何を付けるかでした．パターンは 3 つです．「ラジオ」を付けるか，「FM」を付けるか，何も付けないか．

まず，何も付けない案は，最初に外しました．

名前をパッと聞いたときに，それが何なのかイメージできるかどうか．これが大きな差だと思ったんです．「なんとか FM」「なんとかラジオ」と聞けば，少なくとも音声配信の何かだということは分かりますよね．付けない番組を否定したいわけではまったくなくて，僕の番組としては，認知の観点から選択肢から外した，ということです．付ける一択だと思いました．

次に，「ラジオ」か「FM」か．ここは本当に悩みました．

僕の中には，ラジオへのこだわりがあるんです．ラジオというのは，基本的にはライブでやるもの．それに，今はインターネットラジオもありますけど，基本は電波に乗せて届けるもの．そこがポッドキャストとの明確な違いだと思っています．

ただ，ラジオという言葉もいいんですよ．響きとして残りやすいし，誰にとっても分かりやすい．いい名前があるならラジオでもいい，とこだわらずに考えていて，実際このあと挙げる候補にも「ラジオ」が付いたものがいくつかあります．それでも最終的には，FM のほうにしました．

「.fm」の，ドットと大文字小文字

FM にもさらに細かい分かれ道があって，ドットを付けるか付けないか，そしてドットの後の fm を大文字にするか小文字にするか．こんな細かいところまで，しっかりこだわりました．

結論から言うと，今は小文字の「.fm」です．

ただ本当は，大文字のほうがいいと思っています．番組名が日本語だからです．名前がアルファベットや英単語なら，小文字の「.fm」のほうが統一感も見栄えもいい．全部大文字の名前なら，FM も大文字にするのがいいと思います．でも「雨宿りとWEBの小噺」は完全に日本語なので，それなら大文字もいいな，と思っていたんです．

……なのに，なぜか小文字にしています．理由は，すみません，もう覚えていません（笑）．

ちなみに，僕の公式サイト keeth.me にアクセスしていただくと，冒頭に番組名が出てくるんですけど，右上を押すと英語モードにできるんです．英語モードの番組名も悩んだんですけど，こちらは「Amayadori FM」にしました．こっちの FM は，あえて大文字です．当時調べたら，海外の番組は大文字が多かった印象があったので．

コンセプトとして一番こだわったのが「雨宿り」だったので，英語名はそこだけ残して，短くしました．ただ，あとから調べたら，分かりやすさという観点では，実は長い番組名のほうがいいという説も出てきまして．もしかしたら，英語名のほうは変えるかもしれません．

候補その 1：「雨」にこだわった名前

では，いよいよ候補です．むちゃくちゃあるので，いくつかのグループに分けて読んでいきます．

冒頭でお話ししたとおり，僕は雨が好きなので，最初は「雨宿り」ではなくて，「雨」そのものにこだわっていました．雨が付く名前から，ガーッと考え始めたんです．Web とかテック系の話をすることは決まっていたので，「テック」を付けるか，日本語で「技術」にするかでも悩んでいました．

そこで出てきたのが，このあたりです．

雨宿りテックトークラジオ． 雨音テック FM． 雨宿りとテック FM． テックの雨粒ラジオ． 雨宿り開発ラジオ． 技術の雨宿り FM． 雨宿りクリエイターラジオ．

それから，今の名前にかなり近いものも出てきます．

雨宿り Web 小噺．これは今の名前から「と」と「の」，つまり助詞を抜いたものですね． Web の雨宿り FM． Web 小噺と雨宿り FM．これは順番を入れ替えたものです． 雨宿りと Web 小噺ラジオ． 雨宿りと Web 話 FM． 雨宿りと Web FM． 雨宿り Web トークラジオ．

「Web トークラジオ」は，響きとしてちょっといいなと思っていました．

あとは，ちょっとウィットの効いた，少し異色の名前も考えました．

雨音とテックの交差点．

それでも「雨」を残した理由

ただ，雨を外すことも本気で考えたんです．

僕は雨が好きですけど，一般的に雨って嫌われがちなものですよね．冒頭から雨音が聞こえてきて，いい気分になる人ってあんまりいないんじゃないか，とも思っていました．それに，この番組には，小噺や余談で一呼吸してもらいたいという意味もあるので，雨よりそっちを強めるという手もありました．

それでも最終的には，雨を残しました．ここは完全に僕のエゴです（笑）．ただ，結果的に他の番組にない差別化になっていて，今はしっくりきていると思っています．

候補その 2：雨を外した名前

では，雨を外して考えた名前です．

エンジニアの縁側 FM． エンジニアのトリセツ．

そして，千里の道も一行から FM．

これは残すか，かなり悩みました．プログラミングをやっている方なら分かると思うんですけど，システムもアプリケーションも，結局は 1 行 1 行のコードを積み重ねて，最終的なプロダクトになります．エンジニアの成長も同じで，結局は手を動かして，1 行ずつしっかり書いていく．その積み重ねで強いエンジニアになれる．そんな意味を込めました．

ただ，この番組は強くなるエンジニアとか，プロダクトを作るための話に特化するわけではないので，外しました．でもこの名前は今でも好きで，どこか別のところで使いたいくらいです．

候補その 3：「晴れ」の名前

次は，あえて雨ではなく「晴れ」を使った名前です．晴れと聞けば，結局は雨も連想できるので．

晴れのち Web 談話 FM． 一雨ごとに技術の春 FM． テックの晴れ間 FM．

このあたりはかなり詩的ですよね．正直に言うと，AI に考えてもらったものも混ざっています．でも番組名として面白いなと思いました．「晴れのち Web」は，談話じゃなくて雑談でもよかったし，今喋りながら「晴れのち Web.fm」でもいいなと思っています．「一雨ごとに技術の春」も嫌いじゃないです．雨を越えた先に晴れがある，みたいな，ちょっとポジティブな方向に向かえる感じがあって．

候補その 4：「隠れ家」と「路地裏」の名前

次は，表通りから少し外れた場所の名前です．

テックの隠れ庵 FM．庵というのは，建物の「いおり」のことです． エンジニアの隠れ家ラジオ． 技術の寄り道庵．

庵というのは，小さな小屋のような建物で，お坊さんとか世捨て人が住むような，草庵とも言いますよね．メインで訪れる場所ではなくて，本堂から少し外れたところにある．そういうニュアンスを込めた，一種の暗喩として，いいなと思っていました．

技術の路地裏 FM．

路地裏という言葉も，僕は好きでした．表に出てこない裏話とか本音が聞ける，そんな気配がありますよね．これは結構最後まで残したはずです．

エンジニアの小道ラジオ．

この「小道」は，「小さな道」ではなくて「小路」のほうで，大通りから少し外れた，幅の狭い道のことです．厳密には「こうじ」と読むほうが正しいと思うんですけど，今は「こみち」でも読めるはずです．本道とは少し違う道を歩む，違う目線の話をする．裏話や小噺をする番組だということを，暗に示せていいなと思いました．

エンジニアの裏側ラジオ．

候補その 5：言葉遊びの名前

次は，言葉やことわざを使った名前です．

デプロイ前夜 FM．デプロイというのは，作ったものを本番の環境に出す作業のことです．ただ，誰かがもうやっていそうな気がしたのと，僕自身あまりデプロイという言葉に思い入れがなかったので，外しました．

習うより慣れろ FM．エンジニアの格言をそのまま使ったものですね．

技術の散歩道．これも FM を付けてよかったかもしれません．散歩のように，ぶらぶら歩きながら，いろんな技術に軽く触れていく．技術の世界を歩こう，という感じが，いいなと思いました．

エンジニアの徒然日記．日々いろんな体験をしたり，考えたり，チャレンジしたり，というところから付けたんですけど，「徒然」という言葉は世の中のいたるところで使われすぎているので，差別化にならないなと思ってやめました．

晴れでも雨でも技術トークラジオ．コンセプトとしては嫌いじゃないんですけど，正直長いし，ハッシュタグをどうするんだという問題があってやめました．

エンジニアの怠惰な午後．これはエンジニアの三大美徳から取っています．Perl という言語を作ったラリー・ウォールさんが，プログラマーの美徳として「怠惰，短気，傲慢」を挙げているんですね．エンジニアなら響くけど，一般的には「怠惰」はネガティブな言葉すぎる．そこを天秤にかけて外しました．ちなみに，なぜ午後なのかというと，エンジニアは朝が弱い人が多いので（笑），そういうのも込めていた気がします．

候補その 6：「余白」と「道の駅」

ここからは，僕が特に悩んだ名前です．

テクノロジーの余白 FM．

「余白」というキーワードが，僕はめちゃくちゃ好きなんです．これは使うか本気で悩みました．でも，聞いた人が「余白って何？」となるだろうなと思って，使いませんでした．

テクノロジーの道の駅ラジオ．

道の駅って，もうそのまんま分かりやすいじゃないですか．直接的に「休む場所」を表している．これを思いついたときは，本当に「これ来たんじゃね？俺天才じゃね？」とちょっと思いました（笑）．結局使っていないんですけどね．でも今聞いても，いいと思います．

候補その 7：エンジニアの休日.fm

最後の候補グループで，これもすごく好きな名前です．

エンジニアの休日.fm．

これは，吹奏楽の「トランペット吹きの休日」という曲から取っています．運動会で絶対に聞いたことがある，と言いたくなる曲です．「星条旗よ永遠なれ」と同じくらい，みなさん聞いたことがあると思います．ぜひ一度，YouTube で調べて聴いてみてください．

何が好きかというと，この曲，むちゃくちゃ速いんですよ．リレーで流れる代表曲，という感じで．「休日」と言っておきながら，疾走感抜群の，忙しい曲なんです．そのギャップが面白くて．曲自体も僕はめちゃくちゃ好きです．駆け抜けるような疾走感のある曲が，なんだかんだ好きなので．性格はネガティブなのに，というツッコミはちょっと置いておいてください（笑）．

で，エンジニアって，休日こそ自分の能力を発揮する人が多いんですよ．好きな開発をしたり，好きな勉強をしたり，技術を無駄遣いして面白いものを作ったり．だからこそ，休日のエンジニアみたいに趣味全開の話をする番組，というのはいいんじゃないか．これはかなり悩んで，最終候補にも入れました．

正直，今この候補の一覧を見ていても，こっちの名前に変えたいなと思うものがたくさんあります．今の番組のサブとして別の番組を無理やり作って，この名前を使いたいと思っちゃうくらい，気に入っている名前があります．まあ，それは置いておいて．

最後は，3 つの AI に採点してもらった

こうやって，思いつく候補をひたすら書き出して，最後にどうしたか．

当時人気だった AI を，僕の独断と偏見で 3 つ選んで，採点してもらいました．ChatGPT と，Gemini と，Perplexity です．当時 Claude がどれくらい使われていたかは，ちょっともう覚えていません．僕が課金していたのは ChatGPT だけだったんですけど，それだと条件がそろわないので，3 つとも無料枠で使える一番新しいモデルで，10 点満点で点数を付けてもらいました．3 つの AI の合計点が一番高いものから選ぼう，という作戦です．

まず ChatGPT．満点の 10 点を付けた名前はなくて，最高点の 9 点だったのが，雨宿りテックトークラジオ，エンジニアの縁側 FM，晴れのち Web 談話 FM，エンジニアのトリセツ，エンジニアの隠れ家ラジオ，雨宿り Web 小噺 FM でした．

次に Gemini．唯一 10 点を付けたのが，雨宿りテックトークラジオ．次いで 9.8 点が，雨音テック FM と，雨宿りとテック FM．9.7 点が，テクノロジーの余白 FM．9.6 点が，テックの雨粒ラジオと，テクノロジーの道の駅ラジオでした．

最後に Perplexity．こちらは 10 点が 6 つもありまして，エンジニアの縁側 FM，千里の道も一行から FM，雨音テック FM，一雨ごとに技術の春 FM，テックの雨粒ラジオ，デプロイ前夜 FM です．

3 つの合計点で並べ直すと，上から，雨宿りテックトークラジオ，エンジニアの縁側 FM，雨音テック FM，エンジニアのトリセツ，千里の道も一行から FM，雨宿りとテック FM，となりました．

……でも，僕がいいなと思っていた名前は，あんまり入っていなかったんですよ．しかも，最終的に僕が選んだ名前は，まさかのランク外です（笑）．結局，AI の評価は決めるための材料というか，あくまで参考意見として聞いた，という感じですね．

「雨宿り」「Web」「小噺」を組み立てる

では，最後にどうやって今の名前に決めたのか．

ひとつは，発音です．名前を付けるときに，実際に自分で読んでみたり，収録して発音しやすいか，録ったものを後で聞いて聞き取りやすいか，というのもかなり試しました．

で，母音から始まる名前，特に頭が母音で始まるのは，発音が難しいんです．「い」は口をしっかり横に広げるので，多少変な発音でも聞き取りやすい．でも「あ」「う」「え」「お」は，口の形が近いまま発音できてしまうので，紛らわしい音になりかねないんですよ．

そう考えると，「雨宿り」は「あ」から始まるし，「Web」は「う」から始まる．「う」をきれいに発音するのって，構えてしまって意外と難しいんです．「エンジニア」も「え」から始まります．僕の候補，ほぼ全部発音しづらい名前ばっかりなんですよね．なんでそんな苦労の道を選ぶんだ，という感じですけど（笑）．「小噺」は破裂音がちょっと入りますけど，母音を乗せやすい音なので，まあなんとかなります．

もうひとつが，「技術」か「テクノロジー」か問題です．結果，どちらも使わないことにしました．「技術」と言っても，いろんなものが想像できますよね．ハードウェアの方ならハードの技術を思い浮かべるでしょうし．なので，僕が一番好きな領域である「Web」にしました．僕は Web 業界に育てていただいて，Web のおかげで今食べていけています．Web には感謝しているし，Web が大好きなので．

それから「小噺」．この「噺」は，お話の「話」ではなくて，口偏に「新しい」と書くほうです．落語の「噺」ですね．ちょっとした笑い話のニュアンスが含まれます．

これで，「雨宿り」「Web」「小噺」という 3 つのキーワードがそろいました．あとは，それをパズルみたいにどう組み合わせるか．

Web 雨宿りと小噺.fm． 雨宿り Web の小噺.fm．

順番を入れ替えただけですけど，いろいろ試して，一番響きがよくて，聞き取りやすく，喋りやすいと感じたのが，「雨宿りとWEBの小噺」でした．

ハッシュタグ #web小噺 の話

最後にハッシュタグです．これも死ぬほど悩みました．

今は「#web小噺」にしています．「web」はみんな使うけど，「小噺」とセットで使っている人はあまりいないので，かぶりにくい．

ただ，悩ましいのが入力のしにくさなんです．web はアルファベットで，小噺は漢字でもひらがなでもいいとお伝えしているんですけど，どちらにしても一度日本語入力に切り替えて変換しないといけない．ただでさえハッシュタグを付けて投稿してくださる方は少ないのに，さらにひと手間かけてもらうことになる．そこまでしてこの名前にするのか，というのは本当に悩みました．

でも，誰かのために発信したいという思いもある一方で，まずは僕が好きで，話したくて話している番組です．そちらの重みのほうが大きかったので，最終的には自分の好きな名前のほうを選びました．

というわけで，「雨宿りとWEBの小噺」は，stand.fm の「Web業界の何でも雑談室」から始まって，14 番組の名前集めと，36 のボツ案と，3 つの AI の採点を経て，最後は自分の好きで決めた名前でした．
