### 本題

- 【つかみ】Pythonのロゴは蛇なのに、公式ドキュメントには「爬虫類とは無関係」とはっきり書いてある。公式チュートリアルの一文：「この言語はBBCの番組『Monty Python's Flying Circus』にちなんで名付けられており、爬虫類とは何の関係もありません」
- 【つかみ】しかも続きがあって「ドキュメントでモンティ・パイソンのネタに触れることは、許されているどころか推奨される！」とまで言っている
- 【背景/歴史】作者はオランダ人のグイド・ヴァンロッサム。1989年12月、クリスマス前後の休暇中に「趣味のプロジェクト」としてPythonの実装を始めた
  - 当時の職場はアムステルダムの政府系研究機関（CWI）。オフィスが閉まっていて、家のコンピュータ以外にやることがあまりなかった、と本人が語っている
- 【背景/歴史】Pythonのルーツは、グイドも開発に関わった教育用言語「ABC」。インデント（字下げ）でブロックを表す仕組みはABCから受け継いだもの
  - 目的はABCの後継として、例外処理やAmoebaという分散OSとの連携ができる言語を作ること
- 【メインの小噺・裏話】名前の由来は公式FAQにも書いてある。実装を始めた頃、グイドは1970年代のBBCコメディ『空飛ぶモンティ・パイソン』の台本集を読んでいた
  - 求めていた名前の条件は「短くて、ユニークで、ちょっと謎めいている」こと
  - 本人いわく、少しふざけた気分で付けた「仮の名前（working title）」だった。それがそのまま定着した
- 【メインの小噺・裏話】仮の名前が本名になった例として、他のプロダクトの話にもつなげられる（仮称のまま正式名称になるパターン）
- 【意外な事実や補足】Pythonのサンプルコードでよく出てくる変数名は foo / bar ではなく「spam」「ham」「eggs」
  - これもモンティ・パイソンの「Spam」というスケッチが元ネタ
  - 公式FAQにも「モンティ・パイソンを好きじゃないとダメ？」→「No, but it helps. :)（いいえ。でも好きだと役に立ちます）」というやり取りがある
- 【意外な事実や補足】グイドはコミュニティから「優しい終身独裁者（BDFL: Benevolent Dictator For Life）」と呼ばれ、2018年7月12日にその座を降りた。この呼び名自体もモンティ・パイソン由来のユーモア文化の流れ
  - ※BDFLの呼び名とモンティ・パイソンの直接の関連は要確認。収録前に裏取りするか、言及を外す
- 【意外な事実や補足】ロゴの蛇については「名前は蛇由来ではないが、後から蛇のイメージが定着した」という流れ。ロゴの詳しい経緯は今回の調査では未確認なので、触れるなら要リサーチ
- 【まとめ・締めのひとこと】蛇じゃなくてコメディ番組。真面目そうな言語の名前が実はお笑いのノリで付けられていた、という話。次にPythonのコードで spam と eggs を見たら思い出してほしい
