## 6:41 ①-3 若手カードは今しか切れない

- 若い方に会うと必ず言う話
- 24歳1年目＝**若手カード**．新卒カードが最強だが20代前半も威力抜群
- ★**失敗が許されるカード．会社のリソースで学習し放題の期間**
- 実践の場で大手を振って失敗できるのは今だけ
- コツ：**やる前に話をする**．仮説とプランを語れば通る
- 相談は1枚で：**目的／やること／期間／成功の定義／得たい学び**
- ★**早く失敗して，早く成長して，早く戦力になる**
- 背伸びしないと届かない所で失敗する／会社が傾く失敗は任されない（若手のうちは）

## 8:35 ①-3 続き　使い道は LT 5 分

- 一番いい使い道が**外で喋ること**
- もう1つ＝**パイプを作る**．名前とブログを知ってる程度で十分．あとになるほど効く
- ★**LT，たった5分．勇気を出して**
- ネタは**自分が詰まって抜けた話1個**でいい．社内で説明した内容の流用でも十分
- 5分の型：**スライド5〜8枚／1枚1メッセージ／結論から**
- 探し方：connpass で**「LT枠あり」**→ 枠に申し込んでから中身を作る
- 理由①**学びの密度が変わる**．登壇するとまず自分が勉強する．まとめ方の質が段違い
- 理由②パイプ．SNS繋がらせてください／懇親会で突っ込んだ質問．分からなければ「分かりません」でいい＝**それも若手カード**
- 1回目は恥ずかしい／2回で慣れる／**聞いてる人は意外とポジティブ**
- 小技：**「これが初めてのLTです」**→ 目線が急にあたたかくなる（笑）
- ★**一回の登壇で得られるものは想像の数倍**．機会が訪れる確率が変わる
- **まとめ**：ロールモデル／一生・楽しく／**若手カードで外で喋る**

## 12:52 ②-1 強化系．学び方から学ぶ

- **強化系**．順番に1個ずつ／実践から入って体系は後
- ✂ 一般的には良くない学び方．今も非効率をやってる節
- ★**最初にやるべきは「自分に合う学び方を探す」こと**．一生使える
- 試す候補：**写経／公式ドキュメント通読／人に説明する／先に全体像→あとで手を動かす**
- 合う型が分かると，**新しい言語の「最初の3日」の使い方**が決まる

## 14:29 ②-2 スキルは錆びる

- 結局**書いてきた**．JS→PHP→日本語（笑）／TS は嫌いで AI 頼み（笑）
- 書かないとレビュー速度も精度も落ちた → ★**スキルは錆びる**
- 錆びの兆候：**レビューで「なんか違う」が言語化できない／書き出しの一歩が遅い**
- 効くのは量より**頻度**．週1回でも自分の手で書く時間を残しておく
- ✂ **地図は見ていい．歩くのは自分の足で** → あえて非効率へ
