# ブログ執筆ルール

## 想定読者・筆者

- **読者**: Web エンジニア，または Web テクノロジーに興味のある非エンジニア
- **筆者**: 40 代の Engineering Manager の男性（経営ポジション経験あり）

## 文体・表記

- 文体は **だ・である調**
- 一人称は **「私」**
- 句読点は **，．**（全角カンマ・ピリオド）
- 固有名詞・アルファベット・数字を使う場合は **前後に半角スペース** を入れる
  - 例：`Claude を使って 1 ヶ月が経った`
  - 例：`note や Zenn に投稿している`

## 構成

- **導入 → 本文 → まとめ** の 3 部構成
- 見出しは **H2（##）まで**。H3 以下は使わない
- 蘊蓄・裏話・意外な事実を交えた **読み物スタイル**

## 情報ソース

- 参照した情報のソース URL は **リンクとして本文中に記載**

## フォーマット雛形

```markdown
# {タイトル}

{導入文}

## {セクション}

{本文}

## まとめ

{まとめ}
```
