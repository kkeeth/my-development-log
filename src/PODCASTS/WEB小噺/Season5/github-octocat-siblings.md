# GitHubのOctocatには兄弟がいる？

## 台本

### オープニング

今回のお題は「GitHubのOctocatには兄弟がいる？」です

### 本題

- 【つかみ】GitHubのOctocat，あのタコと猫が合体したキャラクター．開発者なら絶対一度は見たことあるはずで，ノートPCのステッカーにもよく貼られてる．実はあれ，兄弟がいる

- 【背景/歴史：生みの親は誰か】
  - 原画を描いたのはイギリス人イラストレーター，Simon Oxley（サイモン・オクスリー）
  - 彼は1999年ごろ来日し，原宿→福岡に移り住んで約12年間日本で生活した人物
  - 「Idokungfoo（イドクンフー）」という屋号でフリーランスのイラストを描いていた
  - 日本のゆるキャラ文化・かわいい文化が彼のデザインに深く影響している
  - 2004年ごろからマイクロストック写真サービス「iStockphoto」にイラストをアップロードし始め，数ドルで販売していた

- 【メインの小噺：実は兄弟がいた】
  - 2006年，Oxleyがアップした「幾何学的な青い鳥」のイラストを，Twitterの創業チームが発見
  - 当時の購入価格は10〜15ドル，Oxleyに入ったロイヤルティはわずか2〜6ドル
  - そして彼は，**3年間自分の鳥がTwitterのロゴになったことを知らなかった**
  - 2009年，自宅でビールを飲みながらCNNを見ていたら，画面に自分のデザインが映った
  - 「ビールのラベルを確認して，妻を呼んだ」——これが本人の弁
  - 2007年，今度はタコと猫を合体させた「Octopuss（オクトパス）」をアップロード
  - GitHubの創業チームがこれを404エラーページ用に発見，こちらはきちんとOxleyと交渉して独占使用権を取得（Twitterとは対照的）
  - **つまりOctocatとTwitterの青い鳥は同じ作者の兄弟**
  - DigitalOceanのサメ「Sammy the Shark」，Bitlyのフグも同じOxleyの作品

- 【名前の由来：なぜOctocatなのか】
  - Gitには「octopus merge（オクトパスマージ）」という概念がある
  - 通常のmergeは2ブランチを結合するが，octopus mergeは3つ以上のブランチを同時に統合できる
  - タコの触手が複数のブランチをつかむイメージがぴったりで，「Octocat」という名前になった
  - Oxleyはそのつもりで描いたわけではなかったが，偶然の一致が名前に深みを与えた

- 【本当の意味での"兄弟"：Octodexの話】
  - GitHubはイラストレーターのCameron McEfee（キャメロン・マクフィー）を2011年に採用
  - 彼がまずエラーページ用にOctocatをスター・ウォーズとワイリー・コヨーテのパロディで描き直した
  - その後，社内向けにさまざまなコスチューム版Octocatを描き溜めていったのが「Octodex（オクトデックス）」の始まり
  - Octodexは現在160種類以上のOctocatバリエーションを収録している公式ギャラリー
  - アイアンマン版「Ironcat」，コーダー版「Codercat」，女性版「Femalecodercat」，ヤク版「Yaktocat」，サリー（インド衣装）版「Saritocat」など多彩
  - **Octocatの本名は「Mona Lisa」，通称「Mona（モナ）」** ——これはGitHub社員の娘が書いた物語から生まれた名前

- 【意外な事実】
  - Octocatは「絶対に喋ってはいけない」というルールがある（Clippyの失敗を反省して）
  - 正面から見たとき「足は4本＋尻尾」か「触手8本」かはずっと謎のままにされていたが，フィギュア化の際に「5本の触手」という結論が出た
  - GitHubはユーザーが自分でOctocatをカスタマイズできる「My Octocat」サービスも提供している

- 【まとめ・締めのひとこと】
  - Octocatの生みの親Simon Oxleyは，2026年4月4日，56歳で亡くなった
  - ビール1杯を飲んでいる間に自分のデザインがCNNで流れていたことを知った男が，開発者なら毎日目にする2つのアイコンを残した
  - 彼のポートフォリオサイトには「Simon has passed away, but all his designs and ideas live on.」という言葉が残っている
