0:10オープニング

はい，どうもこんにちは．「雨宿りとWEBの小噺」始まりました．気づきの配達屋 Keeth こと桑原です．

この番組では，普段気にも留めていなかったものに光を当てることで，世界の見え方が少し変わるかもしれない，そんな Web 業界の裏話や小噺をご紹介しております．

  • 今回は番外編／Web Creator Podcast Day 2026／今回13時で気が楽
  • おはがき2通。前回の倍。0通かと思ってた、泣きそう
  • 2通とも「勉強」の話

1:54① ともみさん（24歳・1年目）

  • おはがきを読む（運営配布の紙）→「殻をかぶってる」（笑）／回答悩んだ／大先輩は気恥ずかしい
  • 答えは3つ

3:22①-1 ロールモデルを一人決めて盗む

  • 先輩がすごい＝最高の環境。一人決める／質問は考えてから
  • 盗むのは仕事の進め方＋開発環境（設定には失敗談がある）
  • 言語化できたものだけ盗める
  • 質問の具体：「その設定なんですか」「レビューで最初にどこを見てますか」

4:47①-2 勉強は一生。ただし楽しく

  • 30年現役の先輩も今もキャッチアップ → 生涯勉強は前提
  • 無理はしてほしくない。最強なのは楽しんでる人＝努力を努力と思わない
  • 食べていける武器を作るのも正解。でも嫌いになるくらいなら詰めなくていい
  • 詰めすぎのサイン：休日に触る気がしない／エラー画面を見るのが嫌
  • エンジニアは技術で問題を解決する生き物。分野で縛らず、必要になったら学ぶ

6:41①-3 若手カードは今しか切れない

  • 若い方に会うと必ず言う話
  • 24歳1年目＝若手カード。新卒カードが最強だが20代前半も威力抜群
  • 失敗が許されるカード。会社のリソースで学習し放題の期間
  • 実践の場で大手を振って失敗できるのは今だけ
  • コツ：やる前に話をする。仮説とプランを語れば通る
  • 相談は1枚で：目的／やること／期間／成功の定義／得たい学び
  • 早く失敗して、早く成長して、早く戦力になる
  • 背伸びしないと届かない所で失敗する／会社が傾く失敗は任されない（若手のうちは）

8:35①-3 続き　使い道は LT 5 分

  • 一番いい使い道が外で喋ること
  • もう1つ＝パイプを作る。名前とブログを知ってる程度で十分。あとになるほど効く
  • LT、たった5分。勇気を出して
  • ネタは自分が詰まって抜けた話1個でいい。社内で説明した内容の流用でも十分
  • 5分の型：スライド5〜8枚／1枚1メッセージ／結論から
  • 探し方：connpass で「LT枠あり」→ 枠に申し込んでから中身を作る
  • 理由①学びの密度が変わる。登壇するとまず自分が勉強する。まとめ方の質が段違い
  • 理由②パイプ。SNS繋がらせてください／懇親会で突っ込んだ質問。分からなければ「分かりません」でいい＝それも若手カード
  • 1回目は恥ずかしい／2回で慣れる／聞いてる人は意外とポジティブ
  • 小技：「これが初めてのLTです」→ 目線が急にあたたかくなる（笑）
  • 一回の登壇で得られるものは想像の数倍。機会が訪れる確率が変わる
  • まとめ：ロールモデル／一生・楽しく／若手カードで外で喋る

11:34② ガチ太郎さん

  • おはがきを読む（運営配布の紙）→ 気恥ずかしい
  • 質問は3つ：勉強法／キャリア／ポッドキャスト

12:52②-1 強化系。学び方から学ぶ

  • 強化系。順番に1個ずつ／実践から入って体系は後
  • 一般的には良くない学び方。今も非効率をやってる節
  • 最初にやるべきは「自分に合う学び方を探す」こと。一生使える
  • 試す候補：写経／公式ドキュメント通読／人に説明する／先に全体像→あとで手を動かす
  • 合う型が分かると、新しい言語の「最初の3日」の使い方が決まる

14:29②-2 スキルは錆びる

  • 結局書いてきた。JS→PHP→日本語（笑）／TS は嫌いで AI 頼み（笑）
  • 書かないとレビュー速度も精度も落ちた → スキルは錆びる
  • 錆びの兆候：レビューで「なんか違う」が言語化できない／書き出しの一歩が遅い
  • 効くのは量より頻度。週1回でも自分の手で書く時間を残しておく
  • 地図は見ていい。歩くのは自分の足で → あえて非効率へ

16:58②-3 チャンスがあったら手を挙げる

  • さっきの若手カードを僕自身が切った話
  • ゆめみのチャレンジ取締役。1年目ひより、2年目に応募
  • 半年は置物「なんて世界に飛び込んだんだ」／でも視座が変わった
  • 「根拠のない自信と、それを裏付ける努力」（南場さん・茂木さん）
  • 自信はない。でも「やります」と言う。言ったから頑張る。この順番
  • 言ったあとの埋め方：分からない言葉はその場で聞く／前提の資料を遡って読む

18:51②-4 ポッドキャストは先に始める

  • 勉強してから喋ってない。喋るために勉強してる
  • さっきのLTと同じで、やらないと身につかない／2020年3月の初回は撮り直したい
  • 再生数は回らない → 数字のために始めたんじゃないはず
  • 1本の流れ：ネタ→裏取り→台本→収録→編集。これを回すと毎週勉強が発生する
  • 今ならスマホ1本。マイクも凝らなくていい。見直しは始めてから
