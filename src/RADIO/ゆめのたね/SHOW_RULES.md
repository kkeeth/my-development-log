# キッカケ便 — 番組ルール

このファイルは「キッカケ便」の台本を書くときの参照元である．
定型文や構成を変えたいときは，各回の台本ではなくこのファイルを直す．
ポッドキャスト「雨宿りとWEBの小噺」（`src/PODCASTS/WEB小噺/SHOW_RULES.md`）とは別番組なので混同しないこと．

## 番組概要

- **番組名**：キッカケ便〜次の一歩の問い〜（局から 14 字以内と指定されて付けた仮の副題．副題ごと見直し中）
- **放送局**：ゆめのたね放送局 グリーンチャンネル（東京スタジオ）
- **放送枠**：毎週水曜 朝 9:00〜（30 分）
- **パーソナリティ**：気づきの配達屋 キースこと桑原
- **コンセプト**：次の一歩を探している方に，**答えではなく，問いをお届けする**
- **想定リスナー**：モヤモヤしている方，次の一歩を探している方．エンジニアに限らない
  - WEB 小噺と違って**技術は主役にしない**．IT の話をするときも，業界の外の人が聞いて分かる言葉に置き換える
- **番組の約束**：毎回，エンディングトークで**今週の問い**を 1 つお渡しする．答えは番組では言わない

## 尺の目安

放送枠は 30 分．読み上げは **300 字/分** で見積もる（ラジオは WEB 小噺よりゆっくり話す）．
BGM・ジングル・定型文で 3〜4 分使う前提で，トークの合計は **26 分前後**．

| パート | デビュー回 | 通常回 |
| --- | --- | --- |
| タイトルコール〜提供クレジット | 1 分 | 1 分 |
| トーク本番 | 20〜21 分（6,000〜6,300 字） | |
| トーク前編 | | 10〜11 分（3,000〜3,300 字） |
| トーク後編 | | 10〜11 分（3,000〜3,300 字） |
| エンディングトーク | 3〜4 分（900〜1,200 字） | 3〜4 分（900〜1,200 字） |

- ゲスト回は字数ではなく**質問の数**で管理する（後述）
- 収録で雑談やアドリブが入って伸びる前提なので，**ソロ回も下限に届かなくても水増ししない**
- ⚠️ 要確認：BGM・ジングルの実尺，局アナウンスの有無．分かったらこの表に反映する

## 文体

- です・ます調の話し言葉．一人称は**私**（ライブ収録なので「僕」が出てもよいが，台本は「私」で書く）
- 句読点は `，` `．`（リポジトリ全体の表記に合わせる．耳には出ないので読みやすさ優先）
- 朝 9 時の放送なので，あいさつは**「おはようございます」**
- **耳だけで理解できること**を最優先する．箇条書きや図を前提にしない
- カタカナ語・業界用語は使ったその場で言い換える
  - 例：「1on1，つまり上司と部下が 1 対 1 で話す時間のことですね」
- **答えを言い切らない番組**なので，本題の結論も「私はこうだった」で止める．
  リスナーに「こうすべき」と指示しない
- 主観は言い切る．「〜と思うんですよね」で包まず「〜と思います」
- 問いかけは**今週の問い**に集める．本題の途中で「〜って言えますか？」のようなクイズ調の問いかけを挟まない
- ジングル明けは，前のパートを一言で受けてから入る（「さて，後半です」など）．ラジオは途中から聴き始める人がいる

## 定型文

`{}` の部分だけ回ごとに差し替える．それ以外は一字一句変えない．

### タイトルコール

```
キッカケ便〜次の一歩の問い〜
```

### 番組紹介・提供クレジット

```
みなさん，おはようございます．
ゆめのたね放送局 グリーンチャンネル，水曜朝 9 時です．
パーソナリティは，気づきの配達屋，キースこと桑原です．
この番組では，次の一歩を探している方に「答え」ではなく「問い」をお届けすることで，次のステップへのキッカケを見つけていきます．
今日もどうぞ，最後までお楽しみください．

この番組は，ご縁・応援・貢献をテーマに夢ある番組をお届けする「ゆめのたね放送局」東京スタジオからお送りいたします．
```

**デビュー回だけ**は 1〜2 行目を次に差し替える．

```
みなさん，おはようございます．はじめまして．
今日から，ゆめのたね放送局 グリーンチャンネル，水曜朝 9 時にお邪魔することになりました．
```

**ゲスト回**は「今日もどうぞ」の前に 1 行足す．

```
今日は，ゲストに{ゲスト名}さんをお迎えしています．
```

### 今週の問い（エンディングトークの頭）

```
さて，今週の問いです．

「{今週の問い}」

{問いの補足．1〜3 文．答え方の例やヒントは出さない}

答えは，急いで出さなくて大丈夫です．一週間，ポケットに入れて持ち歩いてみてください．
```

### 締め（エンディングトークの最後）

```
番組への感想や，今週の問いへのあなたの答えは，{お便りの宛先}までお寄せください．

「キッカケ便〜次の一歩の問い〜」，お相手は，気づきの配達屋，キースこと桑原でした．
また来週，水曜朝 9 時にお会いしましょう．いってらっしゃい！
```

ゲスト回は「お相手は」の前に「ゲストは{ゲスト名}さんでした．」を入れる．

⚠️ 要確認：お便りの宛先（局のフォームか，番組独自のフォームか）

## お便りコーナー

いただいたお便りを読んで，そこから話を広げる．

- 1 通から場面を広げる．深夜ラジオのように，送ってくれた人がその場にいるかのように話す
- 本題とつながるお便りを優先する．無い回はコーナーごと飛ばしてよい
- ラジオネームで読む．本名や個人が特定される内容は伏せる
- 「ありがとうを伝えたい」は局が幕間用に用意している共通コーナーなので，この番組ではやらない

## ゲスト回の進め方

ゲスト回は台本を完パケで書かない．**私の台詞（導入・つなぎ・締め）だけ書き，ゲストのパートは質問リストにする**．
ゲストの答えを台本に書くと，収録が「読み合わせ」になって声が死ぬ．

### 事前アンケート（収録の 1 週間前までにゲストに送る）

1. 紹介用プロフィール（100〜150 字．番組で読み上げる）
2. 呼ばれたい呼び方
3. これまでで一番大きかった「次の一歩」は何でしたか
4. そのとき，背中を押したもの（人・言葉・出来事）は何でしたか
5. 誰かに投げかけられて，忘れられない問いはありますか
6. 告知したいこと（イベント，本，SNS など）
7. 話してほしくないこと・NG ワード

### 質問リストの組み方

- **トーク前編**：ゲスト紹介と来歴．アンケート 1〜3 から質問を 4〜5 個
- **トーク後編**：キッカケと問い．アンケート 4〜5 から質問を 3〜4 個＋お便り（あれば）
- 質問は 1 個あたり 2〜3 分で見積もる．**予備の質問を各パート 1〜2 個**持っておく
- 「掘る質問」を用意する．答えが短かったときに「そのとき，どんな気持ちでしたか」「それを言われた場所はどこでしたか」と場面に降りる
- 今週の問いは，**ゲストの話から作る**か，**ゲストに出してもらう**．収録中に決めてよい
